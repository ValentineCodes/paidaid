## 7. Remaining security concerns

| Item | Severity | Notes |
|------|----------|--------|
| **Open `create_escrow` spam** | Medium | Strangers can still create escrows they fund; rate/cost is on-chain, not app-enforced. Full requester binding at create time may need V2.2 + lifecycle work. |
| **Stuck `Releasing` / `Refunding`** | Medium | Contract can fail payout and revert; app reconcile helps **release** path only. No authorized refund recovery UI/RPC. |
| **RPC hash not indexed** | Low | Fund/release may proceed on escrow view alone when tx status RPC misses; failed txs with visible RPC `Failure` are rejected. |
| **Format CI** | Low | `pnpm format:check` repo-wide drift. |
| **No automated E2E** | Informational | Manual Localnet path still required for Intear + full marketplace journey. |
| **Testnet production** | Informational | C1/H1 fixed for explicit testnet env; not deployed or exercised on public testnet in this milestone. |

## 8. Manual Localnet testing instructions

**Prerequisites:** `supabase start`, `supabase db reset`, `pnpm sandbox:start` + `pnpm sandbox:deploy-escrow`, `pnpm dev`, Intear/wallet on **localnet**.

1. Sign in (email/password).
2. **Account → NEAR:** connect wallet (default localnet modules); create link challenge, sign NEP-413 message; confirm message includes your **user id** and **Network localnet**.
3. Post a request; accept as provider (both parties linked).
4. **Engagement → Fund:** `prepare` once; submit create + fund txs; confirm status moves `prepared` → `create_submitted` → `funded` without re-prepare wiping tx hashes.
5. Delivery + requester approve → release escrow; confirm `released` only after on-chain `Released`.
6. **Activity → Payments:** refresh; optional reconcile.
7. **Regression checks:**
   - Set `NEXT_PUBLIC_NEAR_NETWORK_ID=testnet` (and aligned RPC/escrow env) only when intentionally testing testnet modules — default unset should stay localnet.
   - Authenticated client cannot `rpc('load_linked_near_account', …)` via PostgREST (function not granted).

**/contract** demo: unchanged; still uses aligned localnet config.
